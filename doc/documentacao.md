## Documentação

- [Inicio](./../README.md)

O obetivo desta documentação é auxiliar no entendimento e no desenvolvimento de features no SommusGestor.

Inicialmente o foco é documentar o que for mais importante e com o passar do tempo organizar melhor a estrutura de indices e arquivos.

### Orientação para criar os arquivos

- Criar todos os arquivos dentro do diretório `doc` do projeto. Podem ser criados também, sub-diretórios para segmentação das informações, mas sempre devem ficar na pasta `doc` que se encontra na raiz do projeto.

- Sempre utilizar a branch `master` para fazer as documentações. Os links que se encontram no `README.md` possuem uma referência direta a esta `branch`. Se a documentação for feita fora dela, o merge não atualiza os links automaticamente e com isso ficam inconsistentes.

- Por padrão os textos dos arquivos de documentação são em `markdown` (extensão .md). Isso permite uma boa formatação para serem visualizados diretamente no site onde o projeto está.
